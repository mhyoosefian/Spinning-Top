# Spinning Top

MATLAB code for deriving and simulating the equations of motion of a spinning top whose tip rests on the floor (a ball joint), in four ways: the Lagrange and modified Lagrange (quasi-velocity) methods, each with Euler angles (ZYZ) and with quaternions as coordinates. The methods are compared in terms of accuracy (power balance and constraint violation), run time, singularities and the complexity of the equations. A 3D animation of the simulated motion is also included.

**For an explanation of the method and the results, see the project page:**
**https://mhyoosefian.github.io/projects/spinning-top/**

## Requirements

- MATLAB (tested with R2022b)
- Symbolic Math Toolbox (only for `Symb_Deriv.m`)

## How to use the code

- **Compare the four methods:** run `RunMe.m`. Choose the method with the flags `L`, `ML`, `L_quat` and `ML_quat` at the top of the file (1 to use a method), and the input torque with `Moment`. The script plots the generalized coordinates and the error of energy conservation (`Moment = 0`) or of the power balance (`Moment ~= 0`), and, for quaternions, the constraint violation.
- **Animation:** run `RunAnimation.m`. It simulates a 6 cm toy top (its mass and inertia are computed from its shape in `topProfile.m`) with the modified Lagrange method and plays a 3D animation in slow motion. A small friction torque reduces the spin until the rim of the top touches the floor. The settings at the top of the file set the method (`'euler'` or `'quat'`), the initial spin and tilt, the friction, the playback speed, and `saveVideo = 1` to also save the animation as an MP4 file.
- **Derivation:** `Symb_Deriv.m` derives the equations symbolically and writes the generated functions (`MassMat.m`, `Bias.m`, `Bpr_Ml.m`, ...). Running it overwrites these files.

Note: the quaternion functions (`*_quat*.m`) were generated before the sign of the potential energy was corrected to $V = mgh\cos\theta$, so in these functions gravity points upward. `RunAnimation.m` flips the sign of `g` when it uses them, so that both methods simulate the same top (they then agree to about $10^{-11}$).

## Repository structure

```
RunMe.m            simulation and comparison of the four methods
RunAnimation.m     simulation and 3D animation of a toy top
animateTop.m       draws and plays (or records) the animation
topProfile.m       shape of the top and its mass properties
Symb_Deriv.m       symbolic derivation of the equations of motion
ModlagDyn.m, Lag_Dyn.m, ModlagDyn_quat.m, Lag_Dyn_quat.m
                   state derivatives of the four methods
other *.m files    functions generated by Symb_Deriv.m
```
